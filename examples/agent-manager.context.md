# Shared planning context template

Copy this file into the target repository as `agent-manager.context.md`, then
replace every placeholder before launch.

## Objective

- State the approved outcome.

## Accepted decisions

- Record decisions every lane must follow.

## Non-goals

- Record work that is explicitly excluded.

## Contracts and constraints

- Record repository rules, shared interfaces, and ownership boundaries.

## Validation

- Record the acceptance criteria and verification commands.
